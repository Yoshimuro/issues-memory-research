# Сборка колоды и annotations.md

```
python3 -m venv venv && ./venv/bin/pip install python-pptx pillow qrcode
./venv/bin/python slides-build/build3.py 10-slides.pptx annotations.md
```

Колода и `annotations.md` собираются одним запуском из одного источника, поэтому разойтись не могут.

- **Текст речи** — из `06-talk-final.md` (парсится по заголовкам `### 1.2 · …` и полям `**Речь.**`, `**Шапки A/B.**`). Правка текста доклада = правка `06-talk-final.md` + пересборка.
- **Что на экране** — описания лежат в самом `build3.py`, рядом с кодом слайда.
- **Числа** — из прогона `docker/verify.sh` (репозиторий `issues-memory-research`, ветка `v8-talk-verify`), сводка `docker/results/NUMBERS-alpine-node24-arm64.md`. В колоде они записаны руками; менять — вместе с `06-talk-final.md`.
- **Вывод команд** в терминальных окнах — реальный, снят в контейнере, лежит в `frames/*.txt`.

Файлы:

| файл | что |
|---|---|
| `build.py` | «голова»: шаблон X5, клонирование фигур из него, текст, карточки |
| `build2.py` | раскладка по сториборду: зоны A/B, колонка шапок |
| `lib3.py` | терминалы, графики, карта доклада, мини-карта, схемы узлов, QR |
| `build3.py` | сами слайды + описания для annotations |
| `annotations3.py` | сборка `annotations.md` |
| `frames/` | реальный вывод команд для терминальных окон |

**Шаблон.** `build.py` берёт оформление (шрифты X5 Sans, цвета, скруглённые карточки) из `~/Downloads/А. Зайцев.pptx` — путь в константе `TPL`. Без этого файла сборка не пройдёт; поменяйте `TPL` на свой экземпляр шаблона.
