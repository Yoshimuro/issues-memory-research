# Перевод текста доклада в произносимую форму (для TTS)

По этим правилам `speech.json` переведён в `spoken.json`; `python3 build_audio.py check` проверяет результат. Правила одинаковы для всех слайдов, словарь ниже — единственный источник транслитераций.

Голос — русский нейросетевой (ru-RU). Латиницу, цифры, символы и код он читает плохо: латинские слова по буквам или с ошибками, «0.12» как «ноль точка двенадцать», «×6.6» как попало. Задача: переписать текст так, чтобы в нём остались **только кириллические слова и знаки препинания** (. , : ; ? ! — « » и дефис внутри слова) — и чтобы вслух это звучало как живая речь докладчика.

## Жёсткие правила

1. **Кириллический текст не трогать.** Нельзя переформулировать, сокращать, добавлять пояснения, менять порядок слов. Менять можно только: латиницу, цифры, символы, код, разметку — и, если без этого не согласуется, окончание соседнего слова (редко; например «8-ми» → «восьми»).
2. На выходе — ни одной латинской буквы, ни одной цифры, никаких `* ` _ / = % × → ~ ≈ { } [ ] ( )`. Скобки: содержимое сохранить, скобки заменить запятыми или тире так, чтобы фраза читалась.
3. Числа — словами, **в правильном падеже и роде** по контексту: «в 2008 году» → «в две тысячи восьмом году»; «из 30 генераций» → «из тридцати генераций»; «8 форм» → «восемь форм»; «1 форма» → «одна форма».
4. Ремарку `(Разделитель: вопрос, которым закончился прошлый узел, звучит ещё раз — дальше узел на него отвечает. Пауза в пару секунд, пока зал читает слайд.)` целиком заменить на маркер `[пауза]` (единственное исключение из правила 2).
5. Передышки (слайды 15, 25, 40): звучит только фраза в кавычках, перед ней `[пауза]`; ремарка «Пауза на пять секунд…» не читается.
6. Маркдаун убрать: `**`, `*`, обратные кавычки. Пункты списка в Q&A (`- **1. почему не сразу TurboFan?**`) → «Вопрос первый. Почему не сразу Турбофан?», «Вопрос второй. …» — каждый с новой строки.

## Числа — как говорит докладчик

- Десятичные доли миллисекунд — разговорно: `0.12 мс` → «ноль двенадцать миллисекунды»; `0.79` → «ноль семьдесят девять»; `0.80` → «ноль восемьдесят»; `0.13` → «ноль тринадцать».
- Множители: `×6.6` → «в шесть и шесть десятых раза» (или «шесть и шесть десятых раза», если «в» уже есть/не нужно по смыслу); `×2` → «в два раза» / «вдвое» (как естественнее); `×13.5` → «в тринадцать с половиной раз»; `×1.95` → «в один и девяносто пять сотых раза» (разговорно, без «целых»). Если `×N` стоит как подпись (без глагола), всё равно читать «в N раз».
- Диапазоны: `29–31` → «от двадцати девяти до тридцати одного» или «двадцать девять — тридцать один», по контексту; `×5.1–5.4` → «в пять и одну — пять и четыре десятых раза».
- Версии: `Node 24.21.0` → «Нода двадцать четыре, двадцать один, ноль»; `V8 12.4` → «вэ восемь двенадцать и четыре»; `Node 22.9.0` → «Нода двадцать два, девять, ноль»; `V8 14` → «вэ восемь четырнадцать».
- Годы: словами в нужном падеже.
- Проценты: `13%` → «тринадцать процентов»; `+30%` → «плюс тридцать процентов».
- `2302 / 1180 rps` → «две тысячи триста два против тысячи ста восьмидесяти запросов в секунду» (слеш в сравнении A/B читать «против»).
- `30/30` → «тридцать из тридцати».
- `1 → P → N` → «один, потом P, потом N» — с транслитерацией: «один, потом пэ, потом эн».
- `2³` → «два в кубе».
- `1000-го` → «тысячного»; `13 000-го` → «тринадцатитысячного».
- `p99` → «пэ девяносто девять».
