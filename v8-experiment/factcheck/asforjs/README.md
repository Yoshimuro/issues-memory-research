# Проверка выжимки As For JS про V8

Эксперименты проверки фактов по главам выжимки «V8 по материалам канала As For JS». Каждая папка в `experiments/` соответствует части документа; итоговый отчёт появится здесь как `FACTCHECK.md`.

Скрипты — CommonJS (этот `package.json`), запускаются на Node 20/22/24 и d8 15.6.
