# Проверка выжимки As For JS про V8

Проверка всех технических утверждений документа «V8 по материалам канала As For JS: выжимка» (9 глав, 40 пунктов сводки).

- `FACTCHECK.md` — итог: что верно, главные расхождения, вердикты по 40 пунктам сводки, все утверждения с вердиктом «неверно».
- `CLAIMS.md` — все 1169 утверждений с вердиктом, объяснением и доказательством.
- `claims.jsonl` — те же данные в машинном виде.
- `experiments/<часть>/` — скрипты и сырые выводы экспериментов; `*-review/` — перепроверки рецензентов; `lead/` — ручная перепроверка спорных пунктов.

Движки: Node 20.20 / 21.7 / 22.22 / 24.21 (без сжатия указателей) и d8 15.6.67 release и debug (со сжатием указателей). Скрипты — CommonJS (этот `package.json`).
